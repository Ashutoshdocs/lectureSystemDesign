GRAPHQL

Flexible fetching

Ask for exactly the fields you want from one endpoint. No over-fetching.

—
Full IDE: /graphql
WEBSOCKET

Real-time stream

Full-duplex. The server pushes a tick every 2s; send a message and it echoes back.

—
GRPC

Between microservices

HTTP/2 + binary Protobuf on port 50051. Browsers can't call it directly — run a client:

node grpc-client.js <LB_IP>:50051

# or with grpcurl:
grpcurl -plaintext -d '{"a":5,"b":7}' \
  <LB_IP>:50051 demo.Calculator/Add
SOAP

XML envelopes

Enterprise style. WSDL contract at /soap?wsdl. Calls Add(5, 7).

—
WEBHOOKS

Event notifications

Server calls you. Subscribe the built-in receiver, fire an event, read the log.
